## 6. REMEDIATION PLAN

### **Issue 1: SSH Brute-force Attempts**

- **Immediate Actions**:
  - Implement rate-limiting via `fail2ban`.
  - Block offending IPs at the firewall level.
- **Short-term Fix**:
  - Enforce strong SSH key authentication.
  - Disable password authentication.
- **Long-term Solution**:
  - Restrict SSH access via VPN or bastion host.
  - Audit and remove unused user accounts.
- **Code/Config Changes**:
  - Update `/etc/ssh/sshd_config` to disable password auth.
  - Configure `fail2ban` jails for SSH.
- **Monitoring Recommendations**:
  - Alert on >5 failed SSH attempts in 1 minute.

---

### **Issue 2: SMTP Authentication Failures**

- **Immediate Actions**:

- **Short-term Fix**:

- **Long-term Solution**:

- **Code/Config Changes**:
