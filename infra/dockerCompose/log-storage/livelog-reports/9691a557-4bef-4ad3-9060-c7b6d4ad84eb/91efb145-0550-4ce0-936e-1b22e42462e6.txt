## 6. REMEDIATION PLAN

### For the Brute-Force SSH Attack:
- **Immediate Actions**:
  - **Block the attacker's IP address** (`109.107.189.250`) at the firewall or using `fail2ban`.
    ```bash
    # Example using ufw (if enabled)
    sudo ufw deny from 109.107.189.250
    ```
- **Short-term Fix**:
  - Ensure `fail2ban` is installed and configured to monitor SSH logs and automatically ban IPs with repeated failures.
  - Review and tighten `AllowUsers` or `DenyUsers` directives in `/etc/ssh/sshd_config` if not already strict.
- **Long-term Solution**:
  - Implement **Multi-Factor Authentication (MFA)** for SSH access.
  - **Disable password authentication** entirely, using only **SSH key-based authentication**.
  - Change the default SSH port from `22` to a non-standard port.
  - Implement network-level access controls (e.g., security groups, cloud firewalls) to restrict SSH access to known, trusted IP addresses only.
- **Code/Config Changes**:
  - In `/etc/ssh/sshd_config`:
    ```bash
    PasswordAuthentication no
    PermitRootLogin no
    AllowUsers <specific_user>
    Port <non-standard_port>
    ```
  - Restart SSH service after changes: `sudo systemctl restart sshd`.
- **Monitoring Recommendations**:
  - Set up alerts for a high number of `Failed password` or `Invalid user` messages from `sshd` within a short time window (e.g., more than 5 failures in 1 minute).
  - Monitor for new entries in `fail2ban` logs indicating bans.

## 7. PREVENTIVE MEASURES
- **Architectural Improvements**:
  - Place SSH servers behind a **bastion host** or use a **VPN** for access.
  - Use **centralized logging and monitoring** (e.g., ELK stack, Splunk, Prometheus/Grafana) to detect and alert on such patterns across all systems.
- **Additional Logging/Monitoring**:
  - Ensure `fail2ban` logs (`/var/log/fail2ban.log`) are monitored.
  - Log all `sudo` commands to a central location for audit trails.
- **Testing Gaps**:
  - Regular **penetration testing** and **vulnerability scanning** for exposed services.
  - **Incident response drills** for handling brute-force attacks.
