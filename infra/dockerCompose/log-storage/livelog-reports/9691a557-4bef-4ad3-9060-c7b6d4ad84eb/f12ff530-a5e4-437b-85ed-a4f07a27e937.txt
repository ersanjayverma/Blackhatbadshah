## 6. REMEDIATION PLAN

### Immediate Actions
- **Block offending IPs temporarily at firewall level**:
  ```bash
  iptables -A INPUT -s 45.78.224.217 -j DROP
  iptables -A INPUT -s 102.88.137.80 -j DROP
  ```

### Short-term Fix
- **Implement fail2ban** to automatically block IPs after repeated failures:
  ```bash
  apt install fail2ban
  # Configure jail.local to monitor sshd
  ```

### Long-term Solution
- **Enforce key-based authentication only** for SSH.
- **Disable password authentication** in `/etc/ssh/sshd_config`:
  ```
  PasswordAuthentication no
  PubkeyAuthentication yes
  ```

### Code/Config Changes
- Update SSH configuration to restrict access:
  ```conf
  PermitRootLogin no
  AllowUsers specific_user
  ```

### Monitoring Recommendations
- Alert on:
  - More than 5 failed SSH logins per minute from any IP.
  - New invalid user attempts.
- Use SIEM tools to correlate such events across systems.

## 7. PREVENTIVE MEASURES
- **Architectural Improvements**:
  - Place SSH behind a bastion host or VPN.
  - Use non-standard SSH ports.
- **Additional Logging**:
  - Enable verbose SSH logging (`LogLevel VERBOSE`) to capture more context.
- **Testing Gaps**:
  - Conduct penetration testing to identify weak authentication vectors.
  - Regularly audit SSH configurations.
